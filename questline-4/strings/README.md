Valid Palindrome
Iterated through the given string and added those elements which are alphanumeric, in lower case. Performed a join function on the list and checked if the reversed output string is the same as the original output string. True or False is printed accordingly.

Zigzag Conversion
Used a method of creating a list of lists of size numRows. Iterated through each element of string, used a variable d for direction. 1 when it reaches the top list and -1 when it reached the last. Updated pointer with value of d to specify which list has to appended with the string character.
